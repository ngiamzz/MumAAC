# MumAAC

An AAC (augmentative and alternative communication) app for Mum: she taps
letters, picks a word, and the iPhone or iPad speaks it.

See `docs/spec.md` for the design and `CLAUDE.md` for working rules.

## What works now

**Keyboard mode**: large A–Z keys, word suggestions that allow for near-miss
taps, family names offered first, the device's own voice, and it works
offline once installed. It learns where she actually lands on each key from
the words she picks.

Settings for family: press and hold the gear (repeat-tap window, speaking
speed, family names, reset learning).

## Develop

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # unit tests for decoding, touch learning, repeat filter
npm run build    # typecheck + production build into dist/
```

`src/data/words.json` is generated by `scripts/build_words.py` (needs
`pip install wordfreq`) and committed, so the app needs no network.

## Install on her iPhone or iPad

Deploy `dist/` to any static host (Vercel: import the repo, framework "Vite").
Open the URL in Safari, Share → Add to Home Screen. It then opens full screen
and keeps working without internet.
